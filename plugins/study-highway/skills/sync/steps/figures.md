# 4-1. 개념 그림 (anatomy-opt)

이 파일은 `SKILL.md` 4단계가 끝난 뒤, 설정 `figures.enabled`가 true일 때에만 읽는다. `$SCRIPTS`는 `SKILL.md` 원칙에 정의된 스크립트 폴더다.

그림은 `anatomy-opt` 스킬이 만든다. `anatomy-opt`는 개념을 실제 기계 한 대로 그려, 숫자를 바꾸면 부품이 움직이는 등각투영(isometric) HTML 그림(Figure)을 만든다. 이 플러그인의 `skills/anatomy-opt/`에 들어 있다. 비용은 그림 하나에 약 $1(Sonnet 5.5, 긴 세션에서 측정한 값)이므로 사용자가 고른 것만 그린다.

## 1. 후보 고르기

이번에 정리한 자료에서 아래 세 조건을 모두 만족하는 개념만 후보로 한다. 최대 2개다.

1. 숫자 하나를 바꾸면 결과가 연속으로 변하는 모델이 있다(예: 파이프의 유량과 압력, 피스톤의 PV 선도, MOSFET의 게이트 전압과 전류).
2. 슬라이드 두 장 이상에 걸쳐 나온다.
3. 슬라이드에서 확인한 식이나 수치가 있다. 추정한 수치로 그리지 않는다.

조건을 만족하는 개념이 없으면 "이번 자료에는 그림으로 그릴 개념이 없다"고 한 줄 알리고 이 단계를 끝낸다. 식, 알고리즘, 코드 위주의 자료는 대부분 해당하지 않는다.

## 2. 사용자에게 묻기

후보마다 한 줄(개념 이름, 근거 장, 그림에서 움직일 값)을 보여 주고 어느 것을 그릴지 묻는다(AskUserQuestion 도구가 있으면 쓴다). 보기에 "그리지 않는다"를 넣는다. 고르지 않은 후보는 그리지 않는다.

## 3. 그리기

고른 그림마다 하위 에이전트(Agent 도구) 하나에 맡긴다. 하위 에이전트는 새 컨텍스트에서 시작하므로 이 세션의 긴 대화를 다시 읽지 않아 비용이 줄어든다. 대신 이 세션의 내용을 알지 못하므로 요청문에 다음을 모두 넣는다.

- 개념 이름과 한 문단 설명, 슬라이드에서 확인한 식과 수치(근거 장 포함)
- 크기는 Figure이고 Hero가 아니라는 것
- 저장 위치: `<과목 폴더>/.study-highway/figures/<개념 id>/`. 결과는 단독으로 열리는 HTML 파일 하나다.
- 사용자의 문체 지침이 있으면 그림 안의 글에도 적용한다.
- "`study-highway:anatomy-opt` 스킬을 Skill 도구로 호출해 따른다. 호출되지 않으면 `<플러그인 폴더>/skills/anatomy-opt/SKILL.md`를 읽고 따른다."
- 돌려줄 것: HTML 파일 경로, 그림 설명 한 줄, 확인하지 못했거나 추정한 부분

스킬 폴더를 찾지 못하면 `find ~/.claude/plugins -name SKILL.md -path "*study-highway*anatomy-opt*"`로 찾는다. 그래도 없으면 "anatomy-opt를 찾지 못해 그림 단계를 건너뛴다"고 알리고 이 단계를 끝낸다.

## 4. 발행과 연결

- 아티팩트 도구가 있으면 HTML을 발행하고 URL을 얻는다. 없으면 파일 경로를 쓴다.
- 5단계의 그래프 패치에서 그 개념의 항목에 `refs_add`로 `{"label": "그림: <개념>", "url": "<URL 또는 경로>"}`를 더한다. 그래프에 해당 항목이 없으면 항목부터 만든다.
- 6단계 메일 본문에 그림 링크와 "확인하지 못했거나 추정한 부분"을 포함한다.
- 같은 개념의 그림이 `.study-highway/figures/<개념 id>/`에 이미 있으면 다시 그리지 않고 링크만 쓴다. 자료가 수정되어 식이나 수치가 바뀐 경우에만 사용자에게 다시 그릴지 묻는다.
