# study-highway: 강의자료 동기화

새 강의자료를 감지해 정리 문서(장별 보충본과 퀴즈, 또는 예시 위주 예제집) 작성, 지식 그래프 갱신, 알림 메일 발송까지 진행한다.

## 원칙

- **과목마다 따로 만든다.** 그래프, 보충본과 퀴즈 데이터, 기준 기록, 아티팩트 URL은 모두 과목 폴더의 `.study-highway/` 안에 있다. 다른 과목의 그래프를 복사하거나 참고해서 배치를 따라 하지 않는다. 과목마다 개념 구조가 다르므로, 그 과목 자료에 맞게 그룹, 묶음, 배치를 새로 설계한다.
- **자료에서 확인한 것만 쓴다.** 슬라이드에서 추출되지 않은 그림, 수식, 개체는 추정으로 채우지 않는다. 확인하지 못했다고 보충본과 메일에 적는다.
- **사용자의 문체 지침을 따른다.** 사용자가 문체를 지정했으면(예: 쉽고 공식적인 문체) 보충본, 퀴즈, 메일에도 같이 적용한다.
- **비밀번호를 출력하거나 파일에 적지 않는다.**
- 이 스킬 폴더 기준 `../../scripts/`에 스크립트가 있다. 아래에서는 `$SCRIPTS`라고 부른다. 찾지 못하면 `find ~/.claude/plugins -name detect.py -path "*study-highway*"`로 찾는다.
- 스크립트는 `python3`로 직접 부르지 않고 `bash "$SCRIPTS/py.sh"`로 실행한다. `py.sh`는 운영체제마다 다른 Python 명령(`python3`, `python`, `py -3`) 중 동작하는 것을 찾고, 출력을 UTF-8로 맞춘다. Windows에서도 같은 명령을 쓴다.

## 절차

### 1. 과목 폴더와 설정 확인

과목 폴더는 `.study-highway.json`이 있는 폴더다. 현재 폴더에서 위로 올라가며 찾는다. 설정 항목은 다음과 같다.

| 항목 | 뜻 |
|---|---|
| `course` | 과목 이름 |
| `notify_to` | 알림 메일을 받을 주소 |
| `extensions` | 강의자료 확장자. 기본값은 `.pptx`, `.ppt`, `.pdf` |
| `style` | 정리 방식. `"slides"`(장별 보충본과 퀴즈) 또는 `"examples"`(예시 위주 예제집). 없으면 2단계에서 묻는다 |
| `transcript` | 강의 영상 스크립트 사용 여부. `{"enabled": true, "browser": "chrome"}`처럼 쓴다. `browser`는 `"chrome"` 또는 `"edge"`. 쓰지 않으면 `{"enabled": false}`. 없으면 2단계에서 묻는다 |
| `figures` | 개념 그림(anatomy-opt) 사용 여부. `{"enabled": true}`처럼 쓴다. 없거나 false이면 쓰지 않는다. 묻지 않는다 |

설정 파일이 없으면 사용자에게 알리고 멈춘다. 만드는 방법은 `README.md`에 있다.

### 2. 변경 확인

```bash
bash "$SCRIPTS/py.sh" "$SCRIPTS/detect.py" --root "<과목 폴더>" --list
```

`new`와 `modified` 목록, 설정값 `style`, `transcript`가 나온다. 둘 다 비어 있으면 "새 자료가 없다"고 알리고 끝낸다. 목록이 있으면 처리할 파일을 사용자에게 한 줄로 알린 뒤 진행한다.

`first_run`이 true이거나 `style`, `transcript`가 null이면 이 스킬 폴더의 `steps/first-run.md`를 읽고 따른다. 그렇지 않으면 읽지 않는다.

### 3. 슬라이드 텍스트 추출

파일마다 실행한다.

```bash
bash "$SCRIPTS/py.sh" "$SCRIPTS/extract_slides.py" "<파일>"
```

- `.pptx`, `.pdf`는 장별 텍스트가 나온다. 출력의 "텍스트로 추출되지 않음" 줄은 그림, 수식 등이 있다는 뜻이다. 기록해 둔다.
- `.ppt`(구형)는 `extract_slides.py`가 PowerPoint(Windows 또는 WSL)로 복사본을 `.pptx`로 변환해 읽는다. 원본은 수정하지 않고, 변환본은 임시 폴더에만 두며 끝나면 지운다. 사용자가 PowerPoint를 열어 둔 경우에는 PowerPoint를 종료하지 않는다. 장 이미지가 필요하면 `--pptx-out <경로>`로 변환본을 남겨 `Slides(i).Export`에 쓴다. 정리한 `.ppt`는 4단계 이후를 `.pptx`와 똑같이 진행한다. 보충본 `meta.json`의 `unverified`에 ".ppt를 PowerPoint로 .pptx로 변환해 읽었고, 서식이 달라졌을 수 있다"고 적는다.
- PowerPoint가 없어 변환하지 못하면(종료 코드 2) 그 파일은 보충본, 퀴즈, 그래프에 반영하지 않는다. 메일에 ".pptx로 저장해 달라"고 적는다.
- 슬라이드에 글자 없이 그림만 있는 장은 텍스트로 확인할 수 없다. 페이지를 이미지로 바꿔 볼 수 있는 환경이면(`pdftoppm` 등) 이미지를 읽어 확인하고, 확인한 방법을 적는다. 볼 수 없으면 "확인하지 못한 부분"으로 둔다.
- 감지한 파일 중 본인 과제물(보고서 등)처럼 강의자료가 아닌 파일이 있으면 정리 대상인지 사용자에게 먼저 묻는다. 정리하지 않기로 하면 7단계에서 처리 완료로 기록만 한다.

`transcript.enabled`가 true이면 이 스킬 폴더의 `steps/transcript.md`(3-1. 강의 영상 스크립트 수집)를 읽고 따른다. false이면 읽지 않는다.

### 4. 정리 문서 작성

`style`이 `"slides"`이면 이 스킬 폴더의 `steps/slides.md`(4-A. 장별 보충본과 퀴즈)를, `"examples"`이면 `steps/examples.md`(4-B. 예시 위주 예제집)를 읽고 따른다. 다른 방식의 파일은 읽지 않는다.

`figures.enabled`가 true이면 이 스킬 폴더의 `steps/figures.md`(4-1. 개념 그림)를 읽고 따른다. false이거나 없으면 읽지 않는다. 그림을 그리면 5단계 패치에 그림 링크(`refs_add`)를 함께 넣는다.

### 5. 지식 그래프 갱신

그래프 데이터는 `<과목 폴더>/.study-highway/graph.json`이다.

**파일이 있으면 통째로 읽지 않는다.** 크기가 커서 토큰이 많이 든다. 다음 도구로 필요한 부분만 보고 고친다.

```bash
GT="$SCRIPTS/graph_tool.py"
bash "$SCRIPTS/py.sh" "$GT" summary "<graph.json>"           # 항목(id, 이름, 주차, 그룹, 좌표)과 연결 목록. 설명(desc)과 링크(refs)는 빠져 있다
bash "$SCRIPTS/py.sh" "$GT" show "<graph.json>" <id> ...      # 고칠 항목과 그 항목에 닿는 연결의 전체 내용
bash "$SCRIPTS/py.sh" "$GT" patch "<graph.json>" "<패치.json>"  # 변경분만 적용한다 (--dry-run으로 먼저 확인할 수 있다)
```

패치 파일의 형식은 `$SCRIPTS/graph_tool.py` 맨 위 설명에 있다(1~30줄만 읽는다). 새 항목과 연결은 `nodes`와 `edges`에, 기존 항목의 링크는 `refs_add`에, 이번 수정과 확인하지 못한 부분은 `changelog_add`와 `checks_add`에 쓴다.

파일이 없으면 이 과목의 첫 그래프이므로 전체를 새로 쓴다. 형식은 `$SCRIPTS/build_graph.py`의 맨 위 설명에 있다(1~26줄만 읽는다). 파일이 있으면 이 형식 설명은 읽지 않아도 된다.

**항목과 연결을 추가하는 방법**

1. 새 자료의 개념을 항목(node)으로 만든다. 같은 개념이 이미 있으면 새 항목을 만들지 않는다. 기존 항목의 `weeks`와 `desc`를 고치고, 새 연결만 추가한다.
   - 슬라이드 제목에 나오거나 슬라이드에서 정의하는 개념(예: reference model)은 반드시 항목으로 만든다. 묶음(`hulls`) 제목에만 쓰고 항목을 빠뜨리지 않는다. 그 개념의 구성 요소 항목과 `h` 연결로 잇는다.
2. 주차와 관계없이 관련 있는 항목끼리 연결한다. 트리로 만들지 않는다. 순환 연결도 허용한다.
   - `t: "u"`: 앞의 내용이 뒤의 내용에 쓰이거나 적용된다. 화살표로 그린다.
   - `t: "c"`: 서로 비교되거나 대조된다. 점선으로 그린다.
   - `t: "h"`: 분류의 하위 항목이다. 선으로 그린다.
   - 연결마다 짧은 `label`(관계 설명)을 적는다.
3. 연결의 근거를 구분한다. 이번에 슬라이드에서 직접 확인한 연결만 `src`에 "N주차 M장"으로 적는다. 나머지는 `src`를 비운다. `src`는 페이지에 표시되지 않고 `graph.json`에만 남는다. 메일에 근거를 적을 때 쓴다.
4. 그룹(`groups`)은 색 구분이다. 최대 6개다. 주차가 6개를 넘으면 인접한 주차를 묶는다(예: "5~6주차"). `special: true`인 그룹은 id 1 하나만 쓴다. 첫 주차의 개론 내용처럼 나중 내용과 구분해서 보여 주고 싶은 그룹에 쓴다. 필요 없으면 쓰지 않는다.
5. 좌표를 정한다. 빈 곳에 새 항목을 놓고, 관련 항목 근처에 둔다. 묶음(`hulls`)의 크기도 맞춘다. 기존 항목의 좌표는 `summary`에서 본다.
6. 다음을 실행해 겹침이 0건이 될 때까지 좌표와 경로(`sides`, `pts`)를 고친다.

```bash
bash "$SCRIPTS/py.sh" "$SCRIPTS/build_graph.py" "<과목 폴더>/.study-highway/graph.json" --check
```

7. `style`이 `"examples"`이면 `refs`에 그 개념을 쓰는 예제 링크(`<예제집 url>#<예제 id>`)를 단다. 아래 보충본 링크 규칙은 `"slides"`일 때 쓴다.
   보충본이 있는 항목에는 `refs`에 보충본의 해당 장 링크(`<notes_url>#s<장 번호>`)를 단다. 여러 장에 걸친 개념은 소목표 카드(`<notes_url>#sec<소목표 id>`)로 연결한다. 한 항목이 여러 주차에 걸치면 주차마다 링크를 하나씩 단다. 보충본 URL이 아직 없으면 4단계 발행 뒤에 단다.
8. `changelog`에 이번 수정 내용을 한 줄로 더한다. `checks`에는 확인하지 못한 부분(그림, 수식, 읽을 수 없는 파일)을 적는다.
9. HTML을 만들고 발행한다.

```bash
bash "$SCRIPTS/py.sh" "$SCRIPTS/build_graph.py" "<과목 폴더>/.study-highway/graph.json" --out "<과목 폴더>/.study-highway/graph.html"
```

- `artifact_url`이 있으면 그 URL로 다시 발행한다(`url` 지정). 없으면 새로 발행하고, 나온 URL을 `graph.json`의 `artifact_url`에 저장한다.
- 아티팩트 도구가 없는 환경이면 `graph.html` 파일 경로를 알리고 다음 단계로 넘어간다.

### 6. 알림 메일

수신 주소는 `notify_to`다. 없으면 메일을 보내지 않고 사용자에게 알린다. 본문을 임시 파일에 쓰고 보낸다.

```bash
bash "$SCRIPTS/py.sh" "$SCRIPTS/notify.py" --to "<notify_to>" --subject "[강의 정리] <과목> 자료 <N>건 반영" --body-file "<본문 파일>"
```

본문에 담을 내용은 다음과 같다.

1. 정리 문서 링크(`slides`: 파일마다 보충본과 퀴즈, `examples`: 예제집), 지식 그래프 링크
2. 처리한 파일 목록(신규, 수정)과 파일마다 장 수, 퀴즈 문제 수(`slides`) 또는 이번에 더한 예제 목록(`examples`)
3. 정리 문서에서 다룬 주요 내용 몇 줄, 강의 영상 스크립트를 가져왔는지
4. 그래프에서 바뀐 점: 추가한 항목, 추가한 연결, 고친 항목
5. 확인하지 못한 부분과 사용자가 해야 할 일(예: PowerPoint가 없어 변환하지 못한 `.ppt`를 `.pptx`로 저장)

`GMAIL_APP_PASSWORD`가 없으면 발송하지 않고 종료 코드 3으로 끝난다. 이때 본문을 사용자에게 보여 주고, 앱 비밀번호 등록 방법을 안내한다.

### 7. 처리 완료 기록

정리 문서(보충본과 퀴즈, 또는 예제집)와 그래프 반영에 성공한 파일만 기록한다. 강의 영상 스크립트를 가져오지 못한 것은 실패로 보지 않는다. 실패한 파일은 기록하지 않아서 다음 세션에 다시 감지된다.

```bash
bash "$SCRIPTS/py.sh" "$SCRIPTS/detect.py" --root "<과목 폴더>" --commit "<상대 경로>" ...
```

변환해 정리한 `.ppt`는 다른 파일처럼 정리가 끝난 뒤 기록한다. 변환하지 못해 안내 메일만 보낸 `.ppt`는 메일을 보낸 뒤 기록한다. 이후 같은 내용을 `.pptx`로 저장한 파일은 내용이 달라서 새 파일로 다시 감지된다. 이때는 정리 문서(`notes/<id>/`)가 이미 있는지 먼저 확인하고, 있으면 다시 만들지 말고 처리 완료로만 기록한다.

### 8. 폴더 안내 문서 갱신

새 주차 내용을 한 줄로 `<과목 폴더>/.study-highway/flow.md`에 더한다(없으면 만든다). 과목 `CLAUDE.md`는 요청마다 읽혀 토큰이 들기 때문에 주차 목록을 거기에 더하지 않는다. 4-A의 `background`를 쓸 때 이 파일을 읽는다.

### 9. 사용자에게 보고

다음을 짧게 알린다: 처리한 파일, 정리 문서 링크(보충본과 퀴즈, 또는 예제집), 그래프 링크, 그린 개념 그림 링크, 강의 영상 스크립트 반영 여부, 메일 발송 여부, 확인하지 못한 부분.
